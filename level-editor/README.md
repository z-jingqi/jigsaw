# JigCat Level Editor

关卡数据以 Godot 运行时为准。编辑器支持目录排序、主题资源、关卡图片与标题、多边形编辑、凹凸模式 Seed 和异常碎片检查。

## 启动

```bash
pnpm install
pnpm dev
```

- Web: `http://localhost:5174`
- API: `http://localhost:8888`
- `pnpm check` 检查 TypeScript；`pnpm build` 构建。
- API 的 `JIGCAT_REPO_ROOT` 可指定测试数据副本的项目根目录；默认使用本仓库。测试写入时必须使用副本，正式编辑时不要设置此变量。

## 与游戏一致的数据规则

- 支持当前的“主题 → 关卡”结构，也兼容旧分组。排序只改变 `sort_order`，不重命名 ID，避免破坏游戏存档关联。
- 从关卡 `image.path` 读取实际 JPG / PNG / WebP 资源，支持 `res://assets/` 与 `res://levels/`。
- 替换原图仍上传 JPG 3:4；尺寸变化时按比例调整多边形坐标，并清除旧缩略图引用，防止游戏显示旧图。
- 修改某个模式时保留其他模式的自定义参数。保存保留缩略图、背景、多语言和其他现有元数据；中文改名不会清掉英文、日文。
- 多边形生成规则直接读取 `config/puzzle_rules.json`，不在文档中维护另一份版本或尺寸参数。默认目标 36 块，最终数量受尺寸修复影响。
- 新关卡凹凸模式默认 6×8、交换模式默认 5×7；已有配置以原数据为准。
- Seed 数量最少为 1，与游戏一致；手动未选择任何有效碎片时，游戏会回退自动选取。
- 打开关卡不会自动填洞或增加碎片。拖动共享顶点同步移动相邻碎片上的对应点，并限制在图片内；导致自交的移动不应用。
- 合并仅接受共享边且合并后为单个无孔区域的碎片。

## 短边检测

多边形编辑页右侧显示短边检测。默认阈值为原图宽度的 1%，可修改为 0.01–1000 原图像素。

- 检查相邻顶点及首尾闭合边；长度严格小于阈值时标红。
- 反向重复的共享边只计一次，列出关联碎片及边号；点击可选择对应碎片。
- 相邻重复顶点会以 0 长度显示；显式首尾闭合的重复端点不算异常。
- 默认隐藏疑似平滑曲线/共线采样段；勾选后查看全部短分段。该分类根据转角与共享拓扑推测，并非精确的曲线语义，严格检查必须勾选全部。
- 检测只提示，不自动移动、合并或删除点，也不把短边视为游戏必然无法运行。

小碎片检测仍按面积检查，可在关卡树中选择并批量扫描；与短边长度检查是两个独立指标。
