# Home UI asset sources

- `album-3d.webp`: generated for JigCat with OpenAI image generation.
- `settings-3d.webp`: 3D Icons `Setting`, color style, CC0.
  Source: https://3dicons.co/explore
- `progress-paw-3d.webp`: generated for JigCat with OpenAI image generation.
- `theme-card-frame-3d.webp`: generated for JigCat with OpenAI image generation.
- `start-button-3d.webp`: generated for JigCat with OpenAI image generation.

The runtime files were background-removed, alpha-trimmed, resized, and encoded
as transparent WebP assets with the repository image tools.
