# Shared UI icon sources

- `back-arrow-primary.webp`: regenerated from the approved level-list back-arrow
  crop using the home start button as the color and material reference. Its
  surface is mostly smooth with only subtle handmade variation. A uniform
  `#F3E5CE` cream-white sticker border, sampled from the Logo, separates it from
  detailed backgrounds. The file has no baked external shadow.

The solid-blue source and processed intermediates are archived under
`/.artifacts/level-list-redesign/replacement-v3/`. Runtime shadows, when used,
must be implemented in Godot according to `docs/UI_VISUAL_STYLE.md`.
