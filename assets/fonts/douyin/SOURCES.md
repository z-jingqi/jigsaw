# Douyin Sans font source

- `DouyinSansBold.ttf`: Douyin Sans / 抖音美好体 by the Douyin Brand
  Creative Center, downloaded from the official ByteDance Fonts repository:
  https://github.com/bytedance/fonts/tree/main/DouyinSans
- `OFL.txt`: the upstream SIL Open Font License 1.1 distributed with the font.

The font is bundled unmodified and is used for JigCat's bold homepage display
text.
