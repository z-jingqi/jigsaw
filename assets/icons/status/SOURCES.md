# Generated mode status icons

The six runtime WebP files were regenerated directly from the approved
level-list design crops. Each glyph uses one silhouette and one edge: there are
no concentric rims, doubled borders, or baked external shadows.

Solid-blue source PNGs and processed archival files live outside the runtime
path under `/.artifacts/level-list-redesign/replacement-v3/`. Processing uses
background removal, transparent-RGB cleanup, transparent-margin trimming,
resize to 256 px wide, and WebP encoding.

Completed files use the approved sage/olive green from the design; not-started
files use its warm parchment clay. The in-progress dot and all external shadows
are drawn by Godot. See `docs/UI_VISUAL_STYLE.md`.
