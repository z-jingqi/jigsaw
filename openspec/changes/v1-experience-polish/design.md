## Context

见 proposal.md 与 docs/V1_RELEASE_UPGRADE_PLAN.md。九尾狐固定为 topic_01/shanhai_01。当前测试套件暂停，使用正常窗口观察、实际状态与日志，真机体验单独记录。

## Goals / Non-Goals

**Goals:** 共用模块改善三模式质感与交互；清理失效旋转调用链；不中断现有进度。

**Non-Goals:** 不重生成全部关卡，不改变切割拓扑和玩法规则，不增加社交或难度。

## Decisions

- 先记录九尾狐实际三模式，再删除失效旋转参数和几何分支；旧状态读取忽略角度。装饰图标变换保留。
- 用独立绘制模块根据原多边形生成侧面与边缘高光；保持贴图和命中几何，避免整套 3D 迁移成本。
- 每个可中断动作持有并取消旧 Tween；跟手位置保持直接更新，视觉反馈与匹配规则分开。
- UI 复用现有场景与稳定时间轴，按游戏页、完成、模式选择顺序处理。
- 通过已有编辑器桥或正常窗口进入真实场景；不新增测试或篡改基线。外部试玩和真机不可用时保持对应任务未完成。

## Risks / Trade-offs

- 复杂边缘高光可能有锯齿 → 在实际缩放下检查，限制线宽并使用抗锯齿。
- 删除初始化参数影响调用方 → 全仓库追踪，更新调用及现有验证脚本参数，不新增断言。
- 固定样板不能覆盖所有数据 → 抽查不同轮廓和明暗关卡。
- 无真机时无法确认触控和震动 → 桌面仅验证可观察行为，发布任务保持待验。

## Migration Plan

在 feat/v1-experience-polish 上按任务顺序接入。保持关卡 ID、碎片 ID 和存档版本语义，读取旧角度但不恢复旋转。各阶段保留变更前证据；异常时回退对应代码改动，避免删除用户数据。完成全部发布验收后才进入 main PR。
