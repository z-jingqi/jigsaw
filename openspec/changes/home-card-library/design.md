## Context
参见 proposal.md。保留运行中的目录与导航服务，替换首页的旧分页路径。测试套件暂停，使用运行窗口、日志和现场状态检查。
## Goals / Non-Goals
Goals：轻盈且可撤回的主题浏览，真实空主题数据，未来添加关卡即可启用。
Non-Goals：改造游戏棋盘、制造新关卡、自动合并 main。
## Decisions
- 固定三张封面节点复用；方向只影响离场，不影响下一张顺序。独立手势模块保存历史方向，撤回从原方向进入。
- 双列主题目录支持原生触控惯性滚动，关闭时目录下落露出首页；选择可玩封面替换目录路由为关卡列表，并更新后台首页的主题，返回时直接到首页。预告主题目录入口禁用。
- 页面过渡保持导航事务的输入锁与恢复逻辑；使用专门卡片运动模块，距离按视口计算。页面先上提约 1% 高度，再二次加速落下；关闭目录使用同样的下落离场，首页保持位置。
- 浅色背景与线性图标由场景和绘制实现，封面由生成图片经 Python 裁切、缩放、WebP 编码；圆角由运行时裁剪，素材不含投影。
- 新主题 levels 为空即为预告状态。保留原有所有主题，以 catalog 排序为准。
- 全部主题标题以屏幕中心轴水平居中，关闭按钮仍独立固定在同排右上角。
- 首页与目录卡片只显示主题名，移除 subtitle 和 Note；预告状态继续由禁用入口、tooltip 与首页“敬请期待”动作表达。
- 首页标题两侧复用同一祥云纹理，右侧使用水平镜像且不旋转。祥云显示尺寸固定，不随名称长度变化；容器使用纹理实际宽高比，固定间距从祥云纹理边界量到文字边界。
- 标题始终单行，以真实字体宽度持续缩小字号，不使用省略号；窗口变化与主题切换均重新计算。最终文字宽度与两侧祥云、间距组成一组后整体居中，使短名称装饰靠近、长名称装饰向外。长英文验收使用 `the classic mountains and seas`。
- 目录滚动由全局自然滚动控制器负责，包含直接拖动、速度采样惯性、边界阻尼与回弹、点击抑制，并避免桌面触控板重复叠加惯性。
## Risks / Trade-offs
- 快速触控和窗口缩放可能中断动画 → 统一归位并清理运动。
- 插画生成拼图表可能出现分隔边 → 检查裁切成品，源文件保留在 runtime 目录外。
- 编辑器桥不可用 → 正常窗口 CLI 验证，不恢复暂停的套件。
