## Context
参见 proposal.md。保留运行中的目录与导航服务，替换首页的旧分页路径。测试套件暂停，使用运行窗口、日志和现场状态检查。
## Goals / Non-Goals
Goals：轻盈且可撤回的主题浏览，真实空主题数据，未来添加关卡即可启用。
Non-Goals：改造游戏棋盘、制造新关卡、自动合并 main。
## Decisions
- 固定三张封面节点复用；方向只影响离场，不影响下一张顺序。独立手势模块保存历史方向，撤回从原方向进入。
- 双列主题目录支持原生触控惯性滚动，关闭回首页，选择封面更新原首页。
- 页面过渡保持导航事务的输入锁与恢复逻辑；使用专门卡片运动模块，距离按视口计算。页面先上提约 1% 高度，再二次加速落下；关闭时首页从下方归位。
- 浅色背景与线性图标由场景和绘制实现，封面由生成图片经 Python 裁切、缩放、WebP 编码；圆角由运行时裁剪，素材不含投影。
- 新主题 levels 为空即为预告状态。保留原有所有主题，以 catalog 排序为准。
## Risks / Trade-offs
- 快速触控和窗口缩放可能中断动画 → 统一归位并清理运动。
- 插画生成拼图表可能出现分隔边 → 检查裁切成品，源文件保留在 runtime 目录外。
- 编辑器桥不可用 → 正常窗口 CLI 验证，不恢复暂停的套件。
