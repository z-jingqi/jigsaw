# 首页与全部主题改造

## 行为

首页采用浅色云纹底、三张复用的叠放封面、标题、主题目录、设置、撤回和纯文字开始按钮。左右拖动都前进一张，最后一张之后循环；撤回沿上一张离场的方向回收，支持连续撤回。小幅拖动归位，拖动直接跟随指针，不增加追随缓动。

全部主题页使用手机双列、宽屏三列的滚动目录。标题与右上角关闭按钮同排。关闭时目录整页下落并露出首页；无当前标记。点击可玩主题直接进入关卡列表，返回时显示首页且当前主题为刚才进入的主题；保留目录滚动位置。四个正式新主题为花间集、海之境、飞羽、林间，目录中 levels 为空。首页显示敬请期待并禁用开始；运行协调层同样拒绝空关卡列表。

整页导航先上提约 1.2% 视口高度（最多 32 个设计单位），再以二次加速度下落，倾斜约 0.86°。关闭目录时目录向下落出；关卡列表返回首页仍使用回收动画。过渡结束或取消时恢复位置、缩放、透明度、旋转、层级并解除输入锁。减少动态效果使用 120ms 淡变。弹窗仍保留现有弹窗交互。

## 资源

使用内置 imagegen 生成封面与浅色背景；Python/Pillow 裁切、缩放和 WebP 编码。源图说明和复现命令见 `assets/ui/home/library/SOURCES.md`。只改变山海经的主题封面，不改变九尾狐实际关卡图。图标和按钮在运行时绘制。

## 标题与目录滚动调整（2026-09-08）

- 全部主题页的标题以屏幕水平中心为基准，关闭按钮继续固定在同排右上角。
- 首页主题名和目录卡片只显示主题名称，不显示 subtitle 或 Note；预告主题仍通过禁用入口、tooltip 和首页“敬请期待”按钮表达状态。
- 首页主题名左右复用同一张透明祥云素材，右侧绕中心旋转 180°。短标题使用完整装饰宽度，长标题缩窄装饰，为文字保留空间。
- 主题名按当前字体的真实整形结果选择字号。优先完整单行，不能容纳时允许最多两行；窗口变化和主题切换时重新排版。验收样例使用 `the classic mountains and seas`，需要检查文字完整、标题框未被最小尺寸撑开，并且祥云与两行文字整体垂直居中。
- 目录滚动统一使用自然滚动控制器：拖动跟手、松手惯性、边界阻尼与回弹、滚动后抑制误点击，并区分触摸与桌面触控板输入。
