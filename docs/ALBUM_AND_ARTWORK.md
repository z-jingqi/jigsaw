# 相册与关卡内容

## 相册

首页左上角的图片图标进入相册。相册直接展示全部主题和关卡图片，所有图片都能打开，不依赖关卡访问或完成记录，也没有收藏功能和收藏存档。

入口先展示主题封面、主题名字和图片数量；点击主题查看该主题全部作品，“全部图片”查看所有主题的作品。图片点击后进入大图，支持上一幅、下一幅和返回，首尾按钮禁用。大图返回保留图片网格位置，主题返回保留主题网格位置，各主题和“全部图片”分别记住位置。

`AlbumPresenter` 从目录元数据建立浏览模型，`AlbumCoordinator` 管理路由与位置，`AlbumScreen` 复用 `VirtualLevelGrid` 只创建可见行及相邻行的卡片。卡片按主题和关卡组合标识复用，不同主题可以使用相同的关卡 ID。滑出范围或进入大图时释放卡片图片引用；缩略图由 `AlbumThumbnailLoader` 分批加载，同时最多三个请求，缓存最多十六张且估算像素内存不超过 24MiB。复用卡片会核对图片路径，避免旧请求把图片写到其他作品上。

目录保留标题和缩略图路径，相册建模不重新读取每关的拼图几何；`LevelRepository` 的完整配置缓存最多三十二份。完整图片只在大图页打开，原有完整纹理缓存仍最多十二张。`AlbumDetailScreen` 展示作品，`AlbumArtworkMotion` 管理可打断的渐变；快速反向切图保持底层图片不透明，停止后释放过渡层，Reduced Motion 直接进入最终图片。

## 共用视觉样式

首页、主题库、关卡列表、模式选择、游戏、完成页和相册沿用纸白背景、墨绿文字、浅鼠尾草绿控件。设置、暂停和首页手势引导已同步调整，移除旧橙棕面板和额外阴影。设置在竖屏为一列，横屏为两列；相册竖屏两列，横屏至少四列并按可用高度增加列数，保留当前浏览的行或列表底部。空目录显示“暂无图片”，长名字使用省略号。

完成页只显示作品名字、完整图片和“完成”按钮。沿用游戏中拼好的纹理，消除接缝后平滑缩小；没有庆祝文案、玩法名称或顶部按钮。“完成”直接返回关卡列表。

## 资源流程

- `tools/content/level_artwork_plan.py` 保存题材与名字，`shanhai_artwork_prompts.json` 保存当前山海经的九份完整提示词和参考图角色。图像通过内置 Imagegen 单独生成；原图与生成回执保留在忽略的工作资料目录。
- `tools/content/refresh_collection.py prepare` 将关卡原图等比裁切为 1080×1440 WebP（质量 86）和 324×432 缩略图（质量 82）；新处理的封面保持原比例，等比缩放到 900×1200 范围内（质量 86）。统一使用 Pillow Lanczos 和 WebP method 6，禁止直接拉伸不同长宽比的图片。首次调整共处理 168 幅运行图片。
- 猫、狗封面已从 Git `HEAD` 原样恢复为 863×1823、862×1824 的 WebP，首页继续使用完整封面，相册缩略图从恢复后的原图等比裁切生成。三种完成图标使用真实透明 WebP，并启用 mipmap 生成与过滤，避免小尺寸显示和滚动时的边缘锯齿。
- `tools/content/build_polygons.ts` 使用关卡编辑器的正式几何生成器，验证尺寸、邻接和覆盖面积；不能生成的目标片数调整到相邻有效值。
- `refresh_collection.py restyle --work <资料目录>` 只替换山海经的 21 份图片资源，保留已经验收的几何和其他主题图片；`verify` 检查八十幅唯一关卡图、WebP 格式、尺寸和三种玩法的实际片数。
- `refresh_collection.py publish` 只复制通过检查的资源。旧关卡和未引用的旧九尾狐封面、太空猫 JPEG 移出运行目录，备份保留在忽略的工作资料目录中；不会进入 APK。
- `prepare_completion_icons.py` 将图标的 SVG 栅格图处理为 96px 无损 WebP，验证 alpha 与边缘像素。SVG 来源在 `tools/content/mode-icons/`，不参与运行资源导出。
- 封面更新后运行 `prepare_album_covers.py`，经 Python/Pillow 生成 324×432 WebP（质量 82、method 6），并向目录补充 `cover_thumbnail`。当前八张相册封面预览共约 332KB；运行时没有预览字段的旧目录仍可使用原封面。
- `LevelAssetCache` 最多持有十二张纹理和三张源图，避免浏览全部作品后持续增加缓存；当前显示的图片和棋盘保留自己的引用。
