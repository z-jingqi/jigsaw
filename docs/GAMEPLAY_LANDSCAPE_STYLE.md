# 游戏山水界面

## 当前决定

- `topic_01` 游戏使用 `assets/ui/gameplay/shanhai-landscape.webp`。背景按 cover 填满并从顶部对齐裁切，确保宽屏下保留顶部 HUD 安全区；其他主题继续使用 `tabletop-calm.webp`，退出游戏后恢复应用默认桌面背景。
- 游戏顶部不使用底板。左侧为墨绿色暂停双竖线，中间为墨绿色关卡名称和左右祥云，右侧为墨绿色线框灯泡。移除旧橙色图标、图标阴影和标题阴影。
- 标题左右复用同一祥云纹理，右侧水平镜像。标题、间距与祥云作为整体水平居中，并根据可用宽度缩小标题字号。
- 暂停按钮打开独立轻量面板，只提供“继续拼图”和“返回关卡”。面板使用浅米色底、墨绿色文字和按钮，不增加额外功能或装饰。
- 暂停面板通过正式 navigator modal 路由显示。modal 屏蔽棋盘输入，同时协调层暂停 `WorldHost` 处理以停止棋盘动画；继续后恢复。返回关卡先关闭 modal，再走现有 `_return_to_levels`，保留当前拼图状态的持久化行为。
- 托盘毛玻璃不读取跨 `CanvasLayer` 的屏幕拷贝。shader 直接采样与桌面层相同的背景纹理，按当前背景的 cover 规则映射 UV，并使用中心、上下左右和四个对角共 9 次采样形成轻度模糊；随后叠加淡鼠尾草绿色调。山海背景使用顶部对齐映射，其他背景保持居中映射。
