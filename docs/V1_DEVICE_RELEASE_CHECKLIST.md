## 一轮真机检查

建议每位测试者 15–20 分钟，先做九尾狐，再抽查另一关卡。

| 项目 | 操作 | 记录与通过条件 |
| --- | --- | --- |
| 托盘辨认 | 两行来回浏览，连续取走上行碎片 | 可辨认数量、查找耗时、上下行均衡；可用触控单元不少于 44 逻辑点 |
| 直接跟手 | 按住横滑、高速反向、拖出后回到恢复带 | 无明显追赶；锁定／恢复无跳位、不换片；录屏和帧时间单独记录 |
| 惯性 | 快滑松手、停手后松手、惯性中再次按下 | 前者继续减速，停手后不突然滑动，再按立即接管 |
| 拿放 | 无效放下后立刻拿起，正确落位，反复取消 | 不丢片、不重复片、没有旧动画拉回新位置 |
| 交换 | 依次提示、交换、上下左右循环移动 | 跳过正确前缀，移动后唯一占位，目标预览明确 |
| 动态效果 | 开关减少动态效果后重复以上动作 | 跟手一致；四向移动保留轻淡入反馈 |
| 系统中断 | 切后台、锁屏、切回、多指接管 | 不误提交、不残留抓取；继续操作正常 |
| 进度 | 退出、重新启动、继续三模式 | 恢复关卡、模式和已完成进度，不新增固定片 |
| 展示与按钮 | 查看原图、关闭、完成、返回、重新进入 | 无遮挡、误触或裁图；触控面积合适 |
| 连续游玩 | 三模式连续游玩至少 20 分钟 | 记录卡顿、温度、内存变化、崩溃和震动感受 |

输入延迟不能只由节点位置断言推导。记录输入到画面的实际表现；60Hz 设备以每帧 16.7ms 为观察基准，不用桌面帧率代替移动设备结果。
