# 音乐与音效

2026-10-06：全部声音使用 ElevenLabs 网页重新生成，没有试听、复用或参考旧音效。

## 声音方向

延续游戏的纸感、木质与柔和手绘氛围。背景采用稀疏的毡音钢琴、轻柔拨弦和低音量持续音；操作反馈保持短、轻、清楚。

| 动作 | 声音设计 | 处理后长度 |
| --- | --- | --- |
| 点击 | 圆润的单次木质轻叩 | 0.12 秒 |
| 页面转换 | 柔和的丝绒气流滑动 | 0.34 秒 |
| 首页主题切换 | 更轻、更低频的纸面滑动 | 0.32 秒 |
| 拿起碎片 | 纸板轻擦与木质轻响 | 0.24 秒 |
| 放下碎片 | 柔软、低沉的纸板落下 | 0.20 秒 |
| 吸附成功 | 木质扣合与短促清亮余音 | 0.50 秒 |
| 方格交换 | 温和的双叩 | 0.25 秒 |
| 显示提示 | 两个轻柔的琴音 | 1.20 秒 |
| 完成拼图 | 简短的钢琴、钟琴上行音句 | 1.45 秒 |
| 背景音乐 | 轻柔的钢琴、拨弦循环 | 26.67 秒循环 |

背景音乐通过 ElevenLabs 声效生成页面的 Loop 功能生成四版 30 秒录音，采用第 2 版。另有一首 Music 页面生成的两分钟作品《Felt and Petals》，该作品被付费导出提示阻挡，因此没有进入运行资源。

## 运行行为

- 音乐跨页面连续播放，游戏中稍低，设置和完成页面进一步降低；不会随切换关卡重新开始。
- 音乐、音效和震动开关互相独立。关闭音乐会渐弱并暂停，重新打开从原位置恢复。
- 拿起、放下、成功吸附、成功交换和实际显示提示时才产生对应声音。连续拖拽、滚动、吸附范围的进入和离开、延长现有提示保持安静。
- 点击与页面提示有短间隔限制；快速拿起后放下仍保留落下反馈。短音效最多四个并行播放，提示与完成各有独立播放器。
- 离开完成页面时渐弱完成音效。切到后台立即停止操作音效并暂停音乐，回来后恢复音乐并渐入。
- 稳定重复播放的声音提前加载；拖拽每帧没有音频资源加载或节点创建。
- 2026-10-06 调整：背景音乐在原有各页面音量上提高 6 dB，操作音效提高约 7–8 dB。保留游戏中、设置和完成页面的相对音量差异。
- 翻页声音已在 ElevenLabs 重新生成，经过低通、温和动态压缩、去除起音前空白和短尾音处理。它跟随实际转场动画开始播放，准备游戏资源期间保持安静；转场完成后不会补播第二次。
- 首页主题在松手确认切换及撤回动画开始时播放一次专用的轻短反馈。拖动、未达到阈值的回弹、取消手势和程序初始化不会反复触发。
- 2026-10-07 调整：主题卡片使用独立的 `theme_glide` 录音，由新生成的 ElevenLabs 源音进行两级 1200 Hz 低通处理；起音渐入 35 ms、收尾渐出 85 ms，峰值比页面转换声低 3 dB，平均音量低约 4 dB。
- 移除游戏暂停功能后，同步移除暂停页面的音量配置。应用切后台时停止操作音效、暂停音乐，返回前台恢复音乐的生命周期行为仍然有效。
- 转场被取消后，音乐音量立即恢复到实际页面对应的状态。暂停的正式套件仍未执行；本轮观察记录位于 `.artifacts/audio-diagnosis-20261006/`。

## 模块与资源

- `scripts/audio/AudioPalette.gd`：音色路径、各动作音量和间隔。
- `scripts/audio/GameAudioPlayback.gd`：播放器、设置、渐变和应用前后台生命周期。
- `scripts/audio/GameAudioBindings.gd`：按钮、导航及棋盘反馈的连接。
- `assets/audio/sfx/`：9 个 48 kHz、单声道 PCM WAV 源文件，由 Godot 导入并提前加载，避免交互时读取资源。
- `assets/audio/music/soft_tabletop.ogg`：48 kHz、立体声 Vorbis 背景循环。

原始生成文件和筛选记录保存在 `.artifacts/audio-redesign-20261006/`，不会进入 APK。音效源文件合计约 0.44 MB，背景循环约 0.27 MB。主题卡片的处理记录在 `.artifacts/theme-card-audio-20261007/`。

处理工具为 `tools/audio/process_recording.py` 和 `tools/audio/process_music_loop.py`。前者裁去起音前空白、调整长度、限制峰值并软化两端；后者交叠循环首尾，将编码接缝移到较安静的位置，进行极短边缘渐变后压缩。每个文件均检查有效信号、峰值和编码后的接缝。

暂停的正式测试套件没有执行。音量、翻页与主题卡片反馈调整后的桌面观察分别通过 84 项音频检查、19 项切换时序检查，运行窗口正常退出且无脚本错误。短观察脚本在取消关卡列表入口后需要收尾未取回的图片加载请求，完成该收尾后退出无资源告警。正式 APK 中的全部 10 项音频导入资源与当前本地资源一致。
