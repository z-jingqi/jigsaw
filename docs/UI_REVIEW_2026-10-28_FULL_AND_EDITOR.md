## 编辑器修复与功能

1. 按实际 `image.path` 加载 JPG/PNG/WebP，支持 assets 资源，修复正式关卡被判为没有 source.jpg。
2. 保存保留背景、缩略图、多语言和扩展字段；编辑多边形不重置凹凸/交换配置，详情显示真实网格。
3. 排序保留稳定 ID，只改顺序；新建主题/关卡采用当前平铺路径，避免额外的虚拟 levels 目录。
4. 中文改名保留其他翻译。目录保存期间阻止交错操作，避免旧响应覆盖刚新增的条目。
5. 打开不再自动填洞。共享顶点一起移动、边界限位、拒绝自交；拒绝不相邻或带孔区域的合并。撤销/重做保持形状；多块相邻碎片不依赖选择顺序。
6. 替换图片同步缩放轮廓坐标并移除旧缩略图引用。图片 URL 只在上传后更新，不再每次渲染都触发重载。
7. 拒绝缺失字段、重复 ID、非有限坐标等无效写入；损坏 JSON 报错而不静默替换默认数据；JSON 使用临时文件后替换。
8. 增加短边检测面板、可调原图像素阈值、SVG 标记、点击选择关联碎片；共享边去重，识别闭合边与重复顶点。疑似平滑采样段默认隐藏，可切换严格查看。分类是启发式，不会自动修形。
9. 编辑区适配 1024 像素桌面宽度，工具栏换行，目录名称允许换行；小碎片批量结果明确显示检查数和异常数。
