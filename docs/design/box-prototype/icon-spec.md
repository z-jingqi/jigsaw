## 统一几何与显式虚线规则（最新版）
1. 三模式统一32×32原生坐标，无隐藏transform。完成形状定义与未完成边界定义逐字相同。
2. 不再使用stroke-dasharray / dashoffset。未完成由显式短直线/Bezier子段组成，解决整圈累计相位导致的角点左右不一致。
3. 每条结构直边、每组连续Bezier曲线两端留0.8单位角点空白；内部空段1.6，实段目标2.4，根据组长选择整数段数后居中等分。每组首尾严格对称。
4. 蜂巢每条边固定2段，3个六边形复用同一个分段规则；对应角的中心线分段与端点退让一致，消除一侧累计相位不同于另一侧的问题。宽笔画在夹角内部可能接近，不声称每个角内所有像素都完全空白。
5. 凹凸连续C命令作为整组按弧长切分，不在内部Bezier连接点额外断开；切出的子曲线仍是真正三次Bezier，不用折线代替。
6. 交换两方块每边复用相同居中规则；下箭头直接由上箭头所有短段坐标180°映射生成，而不是独立累计相位。
7. 全套未完成统一#888F86、butt端点、round连接、有效线宽1.5。封闭轮廓stroke3并clip到共享几何内部，开放箭头stroke1.5居中。
8. 蜂巢真实透明间隙不变：三对邻边净gap为2.846441、2.846441、2.406512 /32；14px对应1.2453、1.2453、1.05285px。内描边不侵占gap。
9. 本轮三份完成态SVG逐字不变，SHA256记录于验证报告。

## 嵌入与验证
独立SVG直接作为img引用。多个SVG内联同一文档时，必须给每个实例的defs ID及所有href/url引用加相同唯一前缀；预览已处理，自动检查无重复ID。

`segment-audit.json`记录每边/曲线组长度、端点gap、段数、区间。`icon-source-validation.json`验证：同边界定义、无transform/自动dash、所有组镜像对称、18条hex边均2段、swap上下箭头180°映射、gap不变、完成态SHA不变、内联ID唯一。
